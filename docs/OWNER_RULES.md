# Owner rules (permanent)

1. Shown means working. A switch or label must do what it says. What Android does not allow is shown as "Unavailable". Never fake "Applied".
2. No ADB. A normal user never needs a computer or adb. Where Android lets the user do it, the app opens the system settings page.
3. Save, apply, restore. Before an app changes a device setting (brightness, screen timeout, auto-sync and so on) it saves the user's value. When the condition ends (temperature back to about 35 C, battery back to about 35 percent, charger unplugged, profile changed, screen on) it restores. Never leave the phone stuck in a restricted state. Brightness is restored to automatic (adaptive) mode, not to a fixed number. Other settings restore their saved value.
4. Privacy first. Personal data stays on the device. Any cloud flow shows its payload and destination and needs opt-in.
5. Security patches are only called "security patch" when they are one.
